## 4. Діагоналі

Референс робить їх **чотирма різними способами** — не один прийом.

- [ ] **Hero головної, ряд 2:** `linear-gradient(-45deg, #000000 64%, transparent 64%)` на фоні ряду —
      чорний трикутник знизу-зліва.
- [ ] **Нижня смуга «Контакти»** (на всіх 3 сторінках): `linear-gradient(135deg, rgba(23,0,190,0) 36%, #1700BE 36%, #1700BE 100%)`
- [ ] **«Про нас», секція 2:** `linear-gradient(-135deg, #1700BD 16%, #FFFFFF 16%, #FFFFFF 100%)` —
      синій клин у верхньому правому куті.
- [ ] **Контактна панель на «Контакти»:** `linear-gradient(135deg, #1700BD 70%, rgba(23,0,189,0) 70%)` —
      зрізаний нижній лівий кут синьої картки.
- [ ] **Справжній SVG-дивайдер** (єдиний): низ секції «ЯК МИ ПРАЦЮЄМО» на «Про нас» —
      `path d="M0 0v140h1280L0 0z"`, viewBox `0 0 1280 140`, заливка `#FFFFFF`, висота 140px, ≈6.25°.

## 5. Типографіка — головна розбіжність

Наша шкала помітно дрібніша за референс.

| Елемент | Референс | Зараз у темі |
|---|---|---|
| H1 hero | Kanit **94.88px** / lh 1 / 700 | `clamp(2rem, 5vw, 3rem)` → максимум 48px |
| H1 «Контакти» | Kanit 80px / 80px / 700 | те саме 48px |
| H1 «Про нас» | Kanit 60px / 72px / 700 | те саме 48px |
| H2 секцій | Kanit 48px / 57.6px / 700 | `clamp(1.6rem, 3.5vw, 2.25rem)` → максимум 36px |
| H2 «Автопілот» | Kanit **80px**, `letter-spacing: 12px`, uppercase | 36px, без розрядки |
| H4 карток | Kanit 24px / 33.6px / 700 | `h3` 1.25rem = 20px |
| P основний | Open Sans 16px / 28.8px / 500 | 16px / 1.6 = 25.6px |
| Список карток | Open Sans 14px / 26px | успадковує 16px |
| Кнопки | Kanit 20px / 700, padding 15px 40px | 0.95rem = 15.2px, padding 0.85rem 1.6rem |
| Меню шапки | Open Sans 14px / 600 / `rgba(0,0,0,.6)` | Kanit 0.95rem / 600 |

- [ ] Підняти шкалу H1/H2 і привести кнопки та меню до цих значень.
      Мобільні: H1 42px, H2 30px/36px — це вже close to наш `clamp`, треба звірити нижню межу.
