# План SEO-виправлень www.bydcenter.com.ua (бренд: **BYD-Center**)

## Context
SEO-аудит від 2026-11-03 показав таке: сайт не в індексі, немає description/OG/JSON-LD, демо-контент WordPress відкритий для індексації, домен без www не працює, бренд розщеплений між «BYD-Center» і «LeaderAuto», важкі медіа, немає кешування. Користувач вирішив, що основна назва — **BYD-Center**. Мета — виправити все по черзі, щоб сайт коректно індексувався і ранжувався за локальними запитами («СТО електромобілів Чернівці», «ремонт BYD Чернівці»).

Принцип: SEO-логіка — це функціональність, а не дизайн, тому вона йде в плагін `leaderauto-core` (новий файл `includes/class-seo.php`), а редаговані SEO-тексти — в наявну систему «Контент сайту» (`includes/content/schema.php`). У темі правимо лише розмітку (H1, alt, бренд у футері).

Позначки: 🧑 — робить користувач (доступи/зовнішні сервіси), 🤖 — роблю я в коді.

## Етап 0. Що потрібно від вас перед стартом
- Години роботи СТО (для JSON-LD і Google-картки).
- Справжні імена/посади команди для /about/ (або рішення тимчасово сховати блок).
- Доступ до Google-акаунта, на який реєструвати Search Console і Google Business Profile.

## Етап 1. Бренд BYD-Center скрізь (основа для решти)
1. 🧑/🤖 `wp option update blogname "BYD-Center"` і `blogdescription "СТО електромобілів у Чернівцях"` у консолі Railway (і локально `make wp`). Після цього в усіх title, RSS, футері, alt логотипа з'явиться BYD-Center.
2. 🤖 [inc/setup.php](app/wp-content/themes/leaderauto/inc/setup.php): прибрати хардкод `'BYD-Center'` у `document_title_parts`, бо title головної тепер керуватиметься SEO-полем (етап 3).
3. 🤖 `postdeploy.sh`/підказка `core install`: `--title='BYD-Center'`, щоб нове середовище не поверталося до LeaderAuto.
4. 🤖 Перевірити `grep -rn LeaderAuto` у видимих рядках теми/плагіна (футер-tagline, alt, листи з форми) і замінити видимі для клієнта на BYD-Center. Внутрішні імена (text domain, slug теми, префікси функцій) **не чіпаємо**.

## Етап 2. Прибрати сміття з індексу
5. 🧑/🤖 wp-cli на проді: видалити `sample-page` (id 2), запис «Привіт, світ!» (id 1) з коментарем. Категорію «Без категорії» лишити, бо видалити її неможливо.
6. 🤖 `class-seo.php`:
   - `wp_sitemaps_add_provider` → прибрати провайдери `users` і `taxonomies`; `wp_sitemaps_post_types` → лишити тільки `page`.
   - `wp_robots` → `noindex, follow` для author/category/tag/date/attachment-архівів і 404.
   - Вимкнути автор-архіви (`?author=N` → 301 на головну) і прибрати `users` з публічного REST (`rest_endpoints`).
   - `remove_action` для `wp_generator`, `rsd_link`, `wlwmanifest_link`, `wp_shortlink_wp_head`, `feed_links_extra`; comments feed прибрати.
   - Старі адреси `?page_id=10/15/17/13` (старий Divi) → 301 на `/`, `/dealer/`, `/about/`, `/contacts/`.
7. 🤖 [inc/setup.php](app/wp-content/themes/leaderauto/inc/setup.php): прибрати `automatic-feed-links`, бо блогу немає.

9. 🤖 `class-seo.php`:

## Етап 4. Структуровані дані (JSON-LD)
11. 🤖 `class-seo.php` → один `<script type="application/ld+json">` з `@graph`:
    - `AutoRepair` (+`LocalBusiness`) на всіх сторінках: name BYD-Center, url, logo, image, telephone ×2, email, address (PostalAddress, Чернівці, 58007, UA), geo 48.3259/25.9150, `openingHoursSpecification` (з етапу 0), `hasMap` (cid-посилання), `sameAs` (Instagram, Google Maps), `areaServed` Чернівецька обл., `priceRange`;
    - `WebSite` на головній;
    - `FAQPage` на головній і /parts/ з наявних `leaderauto_rows('home'|'parts', 'faq_items')`, тобто ті самі дані, що й на сторінці;
    - `BreadcrumbList` на внутрішніх сторінках.
    Контакти брати через наявні хелпери (`leaderauto_content('contacts', …)`), без дублювання.
12. 🤖 Години роботи: нове поле `hours` на екрані «Контакти» (`schema.php`); вивести також у футері/на /contacts/, щоб розмітка збігалася з видимим текстом.

## Етап 6. Іконка, мова, технічне
19. 🤖 Favicon: згенерувати з логотипа `favicon.ico`, `icon-192.png`, `apple-touch-icon.png` у тему; вивести в `wp_head` (`get_site_icon_url` має пріоритет, якщо іконку задано в Customizer). `/favicon.ico` віддавати файлом.
20. 🤖 [Dockerfile](app/docker/php/Dockerfile): встановити мовний пакет `uk` (`wp language core install uk` у postdeploy або скопіювати `languages/` в образ) і `WPLANG/site language = uk` → «Сторінку не знайдено» замість «Page not found».
21. 🤖 Apache-конфіг в образі (`app/docker/php/` + `a2enmod expires headers`): `Cache-Control: public, max-age=31536000, immutable` для `assets/dist/*` (хешовані), 30 днів для зображень/відео/шрифтів; `mod_deflate` для HTML. Безпекові заголовки: HSTS, `X-Content-Type-Options`, `Referrer-Policy`.
22. 🤖 [inc/enqueue.php](app/wp-content/themes/leaderauto/inc/enqueue.php): `preconnect` до `fonts.gstatic.com` (`wp_resource_hints`).

## Перевірка (після кожного релізу)
- Локально `make site`, потім на проді `curl -s <url> | grep -E 'og:|description|ld\+json|<title|robots'` для 5 сторінок; `curl -sI` для кеш-заголовків і favicon.
- `wp-sitemap.xml` містить рівно 5 URL; `/sample-page/`, `/author/admin/`, `?author=1`, `/wp-json/wp/v2/users` → 404/301; `?page_id=15` → 301 `/dealer/`.
- Google Rich Results Test + validator.schema.org (JSON-LD без помилок), Facebook Sharing Debugger / прев'ю в Telegram (OG).
- PageSpeed Insights mobile до/після (ціль: LCP < 2,5 с, CLS < 0,1).
- Search Console через 1–2 тижні: «Сторінки → Проіндексовано» = 5, жодних помилок.
