# Заявки з сайту — інструкція для менеджера

Кожна заявка з форми на сайті («Контакти», «Запчастини») автоматично потрапляє в адмінку,
навіть якщо лист або повідомлення в Telegram не дійшли.

## Де шукати

wp-admin → пункт меню **Заявки** (іконка конверта). Червоне число біля пункту — кількість
**нових** заявок, яких ще ніхто не взяв у роботу.

Доступ мають адміністратор і редактор.

## Список

| Колонка | Що в ній |
|---|---|
| Дата | коли клієнт надіслав заявку |
| Ім'я | клік відкриває картку заявки |
| Телефон | клік — дзвінок (на телефоні / через софтфон) |
| Авто, Повідомлення | як написав клієнт |
| Статус | Нова (жирним) · В роботі · Виконана · Скасована |

- **Вкладки над списком** — фільтр за статусом.
- **Пошук** — за ім'ям, текстом, авто, нотаткою і телефоном. Телефон можна шукати
  будь-яким шматком цифр: `0980899090`, `899090`, `+38 098…` — формат не важливий.
- **Масова зміна статусу** — позначте заявки галочками → «Дії» → «Статус → …» → «Застосувати».

## Картка заявки

- **Клієнт** — дані, які надіслав клієнт. Їх не можна редагувати.
- **Обробка** — статус і **нотатка менеджера** (домовленості, дата запису тощо). Кнопка «Зберегти».
- **Доставка** — чи дійшла заявка на e-mail і в Telegram: ✓ так, ✗ ні, — канал не налаштований.
  Якщо скрізь ✗, перевірте Налаштування → LeaderAuto.

## Як працювати зі статусами

1. **Нова** — щойно надійшла. Передзвоніть клієнту.
2. **В роботі** — клієнт на зв'язку, авто записане або в ремонті.
3. **Виконана** — роботу зроблено.
4. **Скасована** — клієнт відмовився, спам, дубль.

Видаляти заявки не обов'язково: «Скасована» зберігає історію. Кнопка «У кошик» прибирає
заявку зі списку; з кошика її можна відновити з тим самим статусом.
